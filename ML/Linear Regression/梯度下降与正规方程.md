# 梯度下降与正规方程

## 🧭 梯度下降

梯度指出损失上升最快方向，所以沿反方向更新：

$$w\leftarrow w-\alpha\nabla_wL,\qquad b\leftarrow b-\alpha\frac{\partial L}{\partial b}$$

```python
error = y_pred - y
dw = (2 / n) * X.T @ error
db = 2 * np.mean(error)
w -= learning_rate * dw
b -= learning_rate * db
```

- 学习率太大：振荡或发散；太小：收敛慢。
- 特征尺度差异大时，应标准化；否则损失曲面狭长，梯度下降“之”字前进。
- 监控 loss 曲线，并设置容差或最大轮数，而不是盲信固定 epochs。

## 🧮 正规方程与伪逆

把截距并入设计矩阵：

$$\tilde X=[X\ \mathbf1],\qquad \theta=\begin{bmatrix}w\\b\end{bmatrix}$$

满列秩时：

$$\theta=(\tilde X^T\tilde X)^{-1}\tilde X^Ty$$

数值计算不应显式求逆。更稳健的写法：

```python
theta, *_ = np.linalg.lstsq(X_aug, y, rcond=None)
# 或 theta = np.linalg.pinv(X_aug) @ y
```

| 方法 | 优点 | 局限 |
|---|---|---|
| 批量梯度下降 | 可扩展到大数据与复杂模型 | 需调学习率、迭代 |
| 最小二乘 / 伪逆 | 无学习率，直接得到解 | 特征很多时计算和存储代价高 |

> [!warning] 不可逆不等于无解
> 共线特征会使 $\tilde X^T\tilde X$ 奇异；伪逆仍返回最小范数的最小二乘解，但参数可能不唯一。预测可稳定，单个系数解释却可能不稳定。
