# 三特征线性回归的可视化

## 先回答：需要 4D 吗？

是。三个特征加一个目标值构成 $(x_1,x_2,x_3,y)$ 四个数，完整几何关系在 4D。普通 3D 画布最多把三个量放在坐标轴上；颜色、点大小、动画或切片可以编码第四个量，但都是**投影或条件视图**。

## 方案 A：固定 $x_3$ 的多个 3D 切片

固定 $x_3=c$ 后：

$$\hat y=w_1x_1+w_2x_2+(w_3c+b)$$

此时 $(x_1,x_2,\hat y)$ 是一张普通 3D 平面。并列画 $c\in\{1,2,3,4\}$，可以观察第三个特征如何使平面整体平移。

![[Assets/linear_regression_slices.png]]

这不是完整 4D 可视化；每张图只回答“当 $x_3$ 固定时，$x_1,x_2$ 如何影响预测”。

## 方案 B：预测值 vs 真实值 + 残差图

![[Assets/predictions_residuals.png]]

- 左图越贴近 $y=\hat y$ 对角线，整体预测越准确。
- 右图的残差应围绕 0 随机分布；弯曲、漏斗形或分组结构提示模型假设可能不够。
- 这类诊断图牺牲输入空间位置，却直接展示模型质量，通常比强行画“4D”更实用。

## 可选方案 C：PCA 投影

可以把 $X$ 投影到前两个主成分，再用颜色表示 $y$ 或残差。它适合看样本结构，但 PCA 会丢失信息，而且主成分是特征组合；应明确标注为投影，不能把投影平面误称为原始回归超平面。
