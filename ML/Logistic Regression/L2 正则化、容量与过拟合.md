# L2 正则化、容量与过拟合

高阶映射让边界足够灵活，也可能追逐噪声。L2 在 BCE 后加入权重平方惩罚：

$$J=L_{BCE}+\frac\lambda{2m}\lVert w\rVert_2^2$$

$$\nabla_wJ=\frac1mX^T(p-y)+\frac\lambda m w$$

```python
grad_w = X.T @ (p - y) / m + reg_lambda * w / m
grad_b = np.mean(p - y)  # b 通常不正则化
```

> [!important] 这是 L2 正则化逻辑回归
> “Ridge Regression”通常专指使用平方损失的线性回归加 L2。二者共享权重衰减思想，但这里不应把逻辑回归直接叫作岭回归。

## degree 与 $\lambda$ 是一对旋钮

| 现象 | degree | $\lambda$ |
|---|---:|---:|
| 欠拟合：边界太简单 | 增大 | 减小 |
| 过拟合：边界追逐噪声 | 减小 | 增大 |

- $lambda=0$：无正则化。
- $lambda$ 大：参数更小、边界通常更平滑，但过大也会欠拟合。
- 截距 $b$ 只负责整体基准偏移，通常不惩罚。

## 不要用测试集调参

degree、$\lambda$、阈值和训练轮数都应通过验证集或交叉验证选择。测试集只用于最后一次无偏评估；反复看测试结果再调参，会把测试集也“训练进去”。
