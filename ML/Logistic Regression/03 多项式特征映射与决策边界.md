# 多项式特征映射与决策边界

## 线性边界画不出月牙

决策边界是 $z=0$ 的等值线。当 $z=Xw+b$ 只用原始特征 $(x_1,x_2)$ 时，边界必然是直线；而 moons 数据集两类样本呈交错的月牙形，直线怎么摆都分不开。

办法不是换模型，而是**先把特征换成非线性的**：这正对应[[ML/Linear Regression/01 多特征线性模型与维度|线性回归笔记]]里的提示——"线性"指对参数线性，输入可以先做固定的非线性变换。

## 多项式基展开

把 $(x_1,x_2)$ 展开到 degree 阶：

$$\phi(x_1,x_2)=[x_1,\ x_2,\ x_1^2,\ x_1x_2,\ x_2^2,\ x_1^3,\ \dots,\ x_2^{degree}]$$

```python
def map_feature(x1, x2, degree=4):
    out = []
    for i in range(1, degree + 1):      # i 表示阶数
        for j in range(i + 1):          # j 表示 x2 的指数
            out.append((x1 ** (i - j)) * (x2 ** j))
    return np.column_stack(out)
```

模型仍是 $\hat y=\sigma(\phi(X)\,w+b)$：对 $w$ 线性，对输入非线性。degree 是新的自由度旋钮：

| degree | 边界形状 | 风险 |
|---:|---|---|
| 1 | 直线 | 欠拟合，分不开月牙 |
| 2–3 | 平滑曲线 | 通常较合适 |
| 4+ | 高度弯曲 | 容易过拟合，需配合 $\lambda$ |

## 画非线性决策边界

对网格点做**同样的** `map_feature`，再算概率、取 0.5 等高线：

```python
xx, yy = np.meshgrid(np.linspace(x_min, x_max, 300),
                     np.linspace(y_min, y_max, 300))
grid_poly = map_feature(xx.ravel(), yy.ravel(), degree=degree)
grid_predictions = sigmoid(grid_poly @ w + b).reshape(xx.shape)

plt.contourf(xx, yy, grid_predictions, levels=[0, 0.5, 1], alpha=0.25)  # 填充分类区域
plt.contour(xx, yy, grid_predictions, levels=[0.5], colors='black')      # 决策边界
```

`contourf` 展示整个概率场，`contour` 只取 $P=0.5$ 那一条线。网格点必须经过与训练完全相同的特征映射——这是"训练/预测管线一致"的最小示例。
