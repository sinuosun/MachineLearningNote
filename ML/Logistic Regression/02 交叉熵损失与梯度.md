# 交叉熵损失与梯度

## 为什么不能用 MSE

若沿用[[ML/Linear Regression/02 MSE 与梯度|MSE]]去拟合概率 $a=\sigma(z)$，把 Sigmoid 套进去后损失 $L=\frac1m\sum(\sigma(z_i)-y_i)^2$ 关于 $w$ **不是凸函数**——梯度下降可能卡在局部极小。更根本的是，MSE 对" confidently 错"的惩罚不够。

交叉熵（二元交叉熵 BCE）从最大似然推出，且配合 Sigmoid 后损失是凸的：

$$L=-\frac1m\sum_{i=1}^m\big[y_i\ln a_i+(1-y_i)\ln(1-a_i)\big]$$

- $y_i=1$ 时只剩 $-\ln a_i$：预测概率越接近 1 损失越小；$a_i\to0$ 时损失爆炸。
- $y_i=0$ 时只剩 $-\ln(1-a_i)$，对称同理。
- "自信且错"的样本被指数级重罚。

## 梯度：化简到 $a-y$

对单个样本，链式法则经过 $\sigma$：

$$\frac{\partial L_i}{\partial z_i}
=\frac{\partial L_i}{\partial a_i}\cdot\sigma'(z_i)
=\Big(-\frac{y}{a}+\frac{1-y}{1-a}\Big)\cdot a(1-a)=a-y$$

Sigmoid 导数的自相消是这份简洁的来源。对全部样本向量化：

$$dz=a-y$$

$$\nabla_wL=\frac1mX^T(a-y),\qquad
\frac{\partial L}{\partial b}=\operatorname{mean}(a-y)$$

与线性回归的 $\frac2nX^T(\hat y-y)$ 结构完全一致：$X^T$ 同样在做"把样本误差收回到特征"的反向汇总，推导见 [[ML/Linear Regression/03 为什么梯度里有 X 转置]]。区别只是误差项从 $2(\hat y-y)$ 换成了 $a-y$。

## 与 MSE 的对照

| | 线性回归 | 逻辑回归 |
|---|---|---|
| 出口 | 恒等 $\hat y=z$ | Sigmoid $a=\sigma(z)$ |
| 损失 | MSE | 交叉熵 BCE |
| 损失形状 | 凸 | 凸（Sigmoid + BCE 组合） |
| 误差项 | $\hat y-y$ | $a-y$ |
| 梯度汇总 | $\frac2nX^T(\hat y-y)$ | $\frac1mX^T(a-y)$ |

```python
dz = y_pred - y          # 交叉熵 + Sigmoid 联合求导后的形式
dw = (X.T @ dz) / m      # 与线性回归同构的反向汇总
db = np.mean(dz)
```

> [!note] 代码里看不到损失函数
> 实现中损失从未显式计算——$dz=a-y$ 已经是 $L$ 对 $z$ 的导数，直接可用于参数更新。需要画 loss 曲线监控收敛时再把 BCE 补上。

加上正则化项后梯度只多一项：[[04 L2 正则化与过拟合]]。
