# 二元交叉熵与梯度推导

## 从伯努利似然到 BCE

若 $p_i=P(y_i=1\mid x_i)$，单个二分类标签的概率可统一写为：

$$P(y_i\mid x_i)=p_i^{y_i}(1-p_i)^{1-y_i}$$

最大化全部样本的似然，等价于最小化平均负对数似然：

$$L=-\frac1m\sum_{i=1}^m\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right]$$

这就是二元交叉熵（BCE）。预测越自信却越错误，负对数似然越大；它是无上界的，但不应描述成“损失指数增长”。

## 为什么不沿用 MSE

Sigmoid 后接 MSE 虽然可以优化，但通常不是好选择：

- 它不对应伯努利模型的最大似然；
- 关于参数一般不再保证凸；
- 错得很自信时，Sigmoid 导数接近 0，会使 MSE 梯度变弱。

BCE 与 Sigmoid 组合后，梯度恰好消掉容易饱和的因子。

## 推导 $dz=p-y$

对一个样本：

$$\frac{\partial L}{\partial z}
=\left(-\frac yp+\frac{1-y}{1-p}\right)p(1-p)
=p-y$$

因此向量化梯度为：

$$\nabla_wL=\frac1mX^T(p-y),\qquad
\frac{\partial L}{\partial b}=\operatorname{mean}(p-y)$$

`dz = p - y` 是 $L$ 对 logit $z$ 的导数，**不是 loss 本身**。$X^T$ 仍在把 $m$ 个样本误差汇总到 $d$ 个参数，详见 [[ML/Linear Regression/03 为什么梯度里有 X 转置]]。

## 稳定计算损失

直接计算 `log(p)` 可能遇到 `log(0)`。用 logit 形式更稳定：

$$\operatorname{BCE}(z,y)=\log(1+e^z)-yz$$

```python
loss = np.mean(np.logaddexp(0.0, z) - y * z)
```
