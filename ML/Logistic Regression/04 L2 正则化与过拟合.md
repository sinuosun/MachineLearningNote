# L2 正则化与过拟合

## 高阶项的代价

[[03 多项式特征映射与决策边界|多项式映射]]给了模型弯曲边界的能力，但 degree 越高、自由度越大：模型可能把训练样本围得严丝合缝，边界扭曲出一个个"孤岛"，对新样本的泛化却很差——这就是**过拟合**。这是"能拟合"到"能泛化"的分水岭，也是学习路线中正则化阶段的入口。

## L2 惩罚：让权重的代价变贵

在交叉熵后面加一项权重的平方和：

$$L=L_{BCE}+\frac{\lambda}{2m}\lVert w\rVert_2^2
=L_{BCE}+\frac{\lambda}{2m}\sum_{j=1}^dw_j^2$$

- $\lambda=0$：回到普通逻辑回归。
- $\lambda$ 越大，权重被压得越小，边界越平滑——高阶项要"证明自己值得"才能保住大权重。
- 平方惩罚对小权重宽容、对大权重重罚，效果是让权重整体小而分散；相比 L1（绝对值惩罚、倾向产生稀疏权重），L2 保留所有特征但抑制极端值。

梯度只是在原梯度上加一项：

$$\nabla_wL=\frac1mX^T(a-y)+\frac{\lambda}{m}w$$

```python
dw = (X_poly.T @ dz) / m + (reg_lambda / m) * w
db = np.mean(dz)                # bias 不加正则项
```

## 为什么 bias 不参与正则化

- 截距 $b$ 只控制边界整体平移，**不改变边界的形状与复杂度**；压制它只会造成系统性偏差。
- 极端情形：两类样本比例 99:1，最优解需要一个偏置截距把阈值推到正确位置，正则化它会直接伤害拟合。

## 两个旋钮的权衡

| 现象 | 调 degree | 调 $\lambda$ |
|---|---|---|
| 边界太直、欠拟合 | 调高 | 调小 |
| 边界扭曲、过拟合 | 调低 | 调大 |

模型容量（degree）和正则强度（$\lambda$）要**成对**看：高 degree 配大 $\lambda$ 可以既保留表达能力又不失控；sklearn 里同一思想写作 `C = 1/λ`，见 [[05 NumPy 与 sklearn 对照]]。

> [!warning] 这就是岭回归的思想
> 线性回归 + L2 = Ridge Regression；逻辑回归 + L2 是同一思想在分类上的复用。正则化不是某个模型的补丁，而是"容量换惩罚"的通用手段，之后在神经网络里还会反复出现。
