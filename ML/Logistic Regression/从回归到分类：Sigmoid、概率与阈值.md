# 从回归到分类：Sigmoid、概率与阈值

## 线性分数不是概率

线性回归直接输出 $Xw+b\in\mathbb R$，适合连续目标。二分类的标签是 $y\in\{0,1\}$；若把线性输出当概率，它可能小于 0 或大于 1，也没有合适的概率模型解释。

逻辑回归保留线性分数（logit），再压缩到 $(0,1)$：

$$z=Xw+b,qquad p=\sigma(z)=\frac1{1+e^{-z}}$$

- $z=0\Rightarrow p=0.5$；$z$ 的符号决定默认类别。
- $sigma'(z)=\sigma(z)(1-\sigma(z))$。
- 数值实现应裁剪 $z$ 或分段计算，避免 `exp` 溢出。

```python
def sigmoid(z):
    z = np.clip(z, -500.0, 500.0)
    return 1.0 / (1.0 + np.exp(-z))
```

## 为什么它可以解释为概率

逻辑回归假设**对数几率**是特征的线性函数：

$$\log\frac{p}{1-p}=z=Xw+b$$

反解 $p$ 就得到 Sigmoid。因此“逻辑回归”回归的是 log-odds；分类来自之后的阈值化。

## 阈值不是永远等于 0.5

$$\hat y=\mathbf1[p\ge t]$$

$t=0.5$ 只是误判代价近似对称时的默认值：

- 漏诊代价高：降低阈值，提高召回率；
- 误报代价高：提高阈值，提高精确率；
- 类别不平衡：应结合 PR 曲线、业务成本或验证集选阈值。

> [!note] 概率还可能需要校准
> 分类准确不代表概率可信。“预测 0.8”的样本是否约 80% 为正类，需要用校准曲线或 Brier score 另行检查。

默认阈值的决策边界满足 $z=0$；非线性边界见 [[多项式特征与非线性决策边界]]。概率如何训练出来：[[二元交叉熵与梯度推导]]。
