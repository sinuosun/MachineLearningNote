# 多特征线性模型与维度

## 从一个样本开始

一个样本有 $d$ 个特征：

$$x=\begin{bmatrix}x_1\\x_2\\\vdots\\x_d\end{bmatrix},\quad
w=\begin{bmatrix}w_1\\w_2\\\vdots\\w_d\end{bmatrix}$$

预测是点积：

$$\hat y=x^Tw+b=\sum_{j=1}^d w_jx_j+b$$

## 把所有样本叠成矩阵

约定“每行一个样本，每列一个特征”：

$$X\in\mathbb R^{n\times d},\quad w\in\mathbb R^{d},\quad y\in\mathbb R^n$$

于是矩阵乘法一次计算全部预测：

$$\hat y=Xw+b\mathbf1\in\mathbb R^n$$

```python
y_pred = X @ w + b  # NumPy 会把标量 b 广播到 n 个样本
```

> [!important] 线性指什么？
> “线性”主要指对参数 $w,b$ 线性。输入可以先做固定的非线性变换，例如加入 $x^2$ 后仍可用线性回归拟合多项式。

## 三特征为什么是 4D？

三个输入坐标 $(x_1,x_2,x_3)$ 加上输出 $y$，一个样本是 $(x_1,x_2,x_3,y)$，严格位于四维空间。普通三维图无法同时把四个坐标都作为几何轴。正确做法见 [[三特征可视化]]：切片、颜色编码或诊断图都只展示某个视角，不能称为“完整 4D 图”。
