# 评估指标与模型诊断

逻辑回归输出概率，所以既要评估“分对了吗”，也要评估“概率质量如何”。

## 常用指标

| 指标 | 关注点 | 容易误导的场景 |
|---|---|---|
| Accuracy | 总体分对比例 | 类别严重不平衡 |
| Precision | 判为正的样本有多少真为正 | 漏报代价高时不够 |
| Recall | 真正例中找回多少 | 误报代价高时不够 |
| F1 | Precision 与 Recall 的调和平均 | 不评价概率校准 |
| Log loss | 概率预测质量，重罚自信错误 | 不直接对应某个业务阈值 |
| ROC-AUC | 跨阈值排序能力 | 极不平衡时 PR-AUC更直观 |

混淆矩阵：

$$\begin{array}{c|cc}
&\hat y=0&\hat y=1\\\hline
y=0&TN&FP\\
y=1&FN&TP
\end{array}$$

$$\text{Precision}=\frac{TP}{TP+FP},\qquad
\text{Recall}=\frac{TP}{TP+FN}$$

## 本例的三联诊断

![[Assets/logistic_regression_diagnostics.png]]

1. **训练损失**：应整体下降并趋于平台；上升或剧烈振荡通常表示学习率过大。
2. **测试集混淆矩阵**：把错误拆成 FP 与 FN，而不是只看准确率。
3. **概率分布**：观察两类概率是否分开，以及 0.5 阈值落在哪里。

> [!warning] 一张漂亮边界图不是泛化证据
> 数据只有两个特征时图很直观，但真正判断需要独立测试集或交叉验证。训练 loss 下降只说明优化在工作，不说明测试误差一定下降。
